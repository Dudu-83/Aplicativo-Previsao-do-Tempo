# ☀️ Sun | Rain 🌧️ - Aplicativo de Previsão do Tempo

## 📱 Sobre o Projeto

O **Sun | Rain** é um aplicativo mobile desenvolvido em **React Native** com **Expo**, criado para exibir informações climáticas de diferentes cidades de forma simples, rápida e visual.

O aplicativo apresenta uma interface intuitiva com ícones climáticos, fundo temático e informações básicas sobre o clima em cidades do Espírito Santo.

---

## 🚀 Tecnologias Utilizadas

* React Native
* Expo
* JavaScript
* CSS-in-JS (StyleSheet)

---

## 🎨 Funcionalidades

* 🌤️ Exibição da previsão do tempo
* 🌧️ Ícones personalizados para clima ensolarado e chuvoso
* 📍 Lista de cidades
* 📱 Interface mobile responsiva
* 🎨 Design temático com fundo climático

---

## 📸 Preview do Aplicativo

O aplicativo possui uma interface visual simples e amigável, exibindo:

* Nome das cidades
* Tipo de clima
* Temperatura
* Ícones climáticos

Exemplo:

* Cariacica → Ensolarado - 30°
* Vila Velha → Chuvoso - 17°
* Vitória → Chuvoso - 20°

## ⚙️ Como Executar o Projeto

### 1️⃣ Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd Aplicativo-Previsao-do-Tempo
```

### 3️⃣ Instale as dependências

```bash
npm install
```

### 4️⃣ Execute o projeto

```bash
npx expo start
```

---

## 📲 Executando no Celular

1. Instale o aplicativo **Expo Go** no celular.
2. Execute o comando:

```bash
npx expo start
```

3. Escaneie o QR Code exibido no terminal.
